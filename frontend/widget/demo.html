🤖 RAGBot — Preview del widget

Pegá el bot_id del bot que querés ver (lo sacás del Dashboard → el bot → pestaña Embed) y tocá "Cargar widget". El bot tiene que estar marcado como público para responder.

Cómo embeber en tu sitio

<!-- Agrega esto antes del </body> -->
<script>
  window.RAGBOT_API_URL = "https://tuapi.com";
</script>
<script src="https://tuapi.com/api/v1/chatbots/TU_BOT_ID/widget.js"></script>

O bien, usá el Dashboard → el bot → pestaña Embed para copiar el código exacto (ya incluye la API key, si el bot tiene una configurada).
